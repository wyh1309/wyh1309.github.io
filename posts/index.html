From Virtual Memory to PagedAttention: How Block Tables Map KV Cache

TL;DR PagedAttention is virtual memory for the KV cache. The same idea an OS uses to map virtual pages onto physical frames — a page table — becomes vLLM’s block table that maps logical KV-cache blocks onto physical GPU-memory blocks. Once you see that analogy, PagedAttention and Continuous Batching stop being magic. Why KV-cache memory is a problem During decoding, every generated token attends to all past tokens, so the attention cache grows linearly with sequence length.
